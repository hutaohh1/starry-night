# 星月夜 · 流动的笔触

梵高《星月夜》风格的动态星空：青蓝色卷流、金色星环，以及分层起伏的光带。

[在线欣赏](https://hutaohh1.github.io/starry-night/)

## 使用

直接访问在线网页，或下载 `index.html` 后用浏览器打开。无需安装依赖，无需外部图片或网络资源。

- 暂停 / 继续、流动速度、笔触密度、辉光和曝光调节。
- 保存当前画面为 PNG，支持全屏欣赏。
- 快捷键：空格暂停，F 全屏，S 保存，Esc 退出全屏。
- 自动保存当前浏览器中的调节参数。
- 启用系统“减少动态效果”时，画面完成初始化后默认暂停。

## 渲染

Canvas 绘制粒子笔触，WebGL 2 浮点缓冲累积拖尾，使用柔和辉光和 ACES 色调映射合成最终画面。不支持 WebGL 2 的环境回退到 Canvas。

所有线条由程序生成，是对《星月夜》风格的致意，不是对原画逐像素复刻。

## 部署

通过 GitHub Pages 发布 `main` 分支根目录，更新 `index.html` 并推送后自动部署。
